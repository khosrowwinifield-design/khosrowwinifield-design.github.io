# OC 素材工作台自适应布局设计

## 目标

解决上传图片比例与预览框不一致时的两个问题：素材必须完整可见，同时竖图不能把整张内容卡和右侧编辑区一起拉得过高。

## 已批准方案

每个 OC 卡片拆成两个视觉独立的面板：左侧为深色素材预览面板，右侧为白色内容编辑面板。两者只在外层网格中并列，不再共享统一背景、边框、圆角或等高关系。

## 媒体方向规则

- 宽高比小于 `0.9`：`portrait`，预览列采用较窄宽度，突出竖版作品感。
- 宽高比大于 `1.1`：`landscape`，预览列适度放宽。
- 其余比例：`square`，采用介于两者之间的宽度。
- 媒体尺寸无效或尚未上传：`default`，使用稳定的默认比例和默认列宽。

素材画布始终使用媒体原始宽高比；图片和视频使用 `object-fit: contain`，不裁切内容。媒体加载完成后，方向同时写入画布和最近的 `.oc-workbench`，供布局选择器使用。

## 桌面布局

- `.oc-workbench` 使用内容驱动的两列网格并 `align-items: start`，避免列等高。
- 竖图预览列约 `360px–440px`；方图约 `460px–540px`；横图约 `540px–660px`。
- 右侧编辑面板占据剩余空间，拥有自己的白色卡片背景、边框、圆角和阴影。
- 编辑面板在宽屏中保持 `position: sticky; top: 18px`，浏览较高竖图时提示词仍可见。
- 两面板之间保留约 `18px` 间距，外层不裁切媒体面板。

## 响应式布局

- 工作区容器可用宽度不足 `960px` 时改为单列，取消编辑面板 sticky；判断基于内容区而不是整个浏览器视口，避免侧栏占宽导致断点过晚。
- 单列下素材面板不再强制固定最小高度，媒体宽度跟随容器，仍保持原始宽高比。
- 手机宽度下缩小内边距、控件间距和圆角，提示词区改为单列。

## 状态与兼容性

- 切换到没有素材的标签或删除素材时，方向状态重置为 `default`，避免沿用上一张图的列宽。
- 现有 IndexedDB 素材、提示词自动保存、完成状态、标签切换和上传逻辑保持不变。
- CSS 不依赖固定图片尺寸；布局由 `data-media-orientation` 决定。

## 验收标准

1. 竖图、横图、方图均完整显示，无裁切。
2. 竖图不再导致右侧编辑面板出现大面积空白。
3. 横图获得更宽的预览区域，但不挤压编辑面板至不可用。
4. 空素材状态恢复统一默认布局。
5. 小屏幕改为上下排列，不产生横向滚动。
