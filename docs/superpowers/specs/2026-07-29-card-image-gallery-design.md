# OC 卡片多图画廊设计

## 目标

让每张 OC 卡片在同一个媒体框内管理至少四张图片：主图、副图、物品图、设定图，并通过横向缩略图和左右切换查看；现有视频预览继续保留。

## 交互

- 图片模式包含四个固定槽位：`main` 主图、`secondary` 副图、`item` 物品图、`sheet` 设定图。
- 缩略图横向排列，点击切换；画布左右按钮循环切换四个槽位，空槽位显示上传提示。
- 上传控件支持 `multiple`，从当前槽位开始依次填充空槽位，最多保存四张。
- 每个缩略图显示槽位名称和上传状态，当前槽位有高亮边框。
- 视频仍作为独立模式，单独上传和播放。

## 数据兼容

- 新图片槽位复用现有 IndexedDB `media-assets`，主图槽位继续使用原有 `image` key，因此旧素材自动显示为主图。
- 其他槽位使用 `secondary`、`item`、`sheet` key。
- `normalizeDraft` 增加 `activeGallerySlot`，默认 `main`。

## 视觉方向

延续当前深色素材面板和白色编辑面板：画布保持原始比例，缩略图使用胶囊式横向滚动条，空槽位使用线框占位，图片上传与视频上传按钮保持明显区分。

## 验收标准

1. 至少四个图片槽位可独立上传、查看、替换、删除。
2. 批量选择四张图片后能按顺序填入四个槽位。
3. 图片可通过缩略图、左右按钮和触摸横滑查看。
4. 旧主图和视频仍能正常显示。
5. 现有提示词、完成状态、筛选和自动保存不受影响。
