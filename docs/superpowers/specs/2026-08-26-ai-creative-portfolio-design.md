# AI 创意策划设计师作品集网站设计

## 目标

打造一个可部署到 GitHub Pages 的双语静态单页作品集，服务招聘场景。网站需要证明作者不仅能制作高质量 AI 视频，还具备趋势洞察、创意策划、视觉叙事、生成式技术和项目交付能力。

核心定位：

> 从趋势洞察到 AI 影像落地。

职业标签：AI Creative Strategist / AI 创意策划设计师。

## 受众与成功标准

- 主要受众为招聘方、设计负责人和创意团队。
- 访客在首屏 10 秒内理解作者的岗位定位与核心能力。
- 访客能快速浏览 3 个案例，并看懂作者在每个项目中的具体职责。
- 网站在桌面端和移动端均可阅读，无需后端服务。
- 内容、图片、视频链接和社交信息可通过少量 HTML/JS 修改替换。

## 技术方案

采用纯静态 HTML/CSS/JS，不引入构建工具或运行时依赖。入口为 `index.html`，资源使用相对路径，兼容 GitHub Pages 项目站点。提供 `.nojekyll`、README 部署说明和可选的本地预览方式。

## 信息架构

1. **Hero 首屏**：姓名、双语职位、定位宣言、查看案例 CTA、主视觉/视频占位。
2. **能力闭环**：洞察 → 策划 → 视觉叙事 → AI 生成 → 技术系统 → 交付。
3. **精选案例**：3 个可替换案例卡片，编辑式不等宽网格。
4. **案例详情结构**：背景、洞察、创意策略、视觉方案、AI 技术路径、成片、结果、职责。
5. **AI 视频能力**：分镜、镜头语言、角色一致性、风格控制、生成迭代、剪辑包装。
6. **技术能力**：ComfyUI、LoRA、ControlNet、工作流模块化与复用，强调解决问题与效率提升。
7. **平面能力**：KV、海报、封面、社交物料和视频图形包装，作为完整视觉传播能力的支撑。
8. **工作方法 / 关于我**：brief、洞察、概念、测试、生成、后期、交付。
9. **联系与简历**：邮箱、GitHub、LinkedIn、简历下载占位。

## 视觉方向

- 明亮编辑感，参考设计杂志和创意工作室案例页。
- 米白纸张底色、墨黑文字、深红/珊瑚色强调色。
- 大标题、编号、边栏注释、细网格和充足留白。
- 避免通用 SaaS、紫色渐变和过度科技化模板。
- 使用 CSS 动画完成首屏错落渐显、卡片 hover、滚动进入效果。
- 移动端将网格收为单列，保持清晰层级和可触控尺寸。

## 双语交互

默认中文，导航提供 `中 / EN` 切换。所有主要标题、案例摘要、能力标签和 CTA 都准备英文文案。切换通过前端状态更新文本，不刷新页面；用户选择保存到 `localStorage`。

## 内容占位策略

使用 3 个示例案例占位，明确标注可替换字段：项目名、年份、类型、职责、洞察、策略、工具、结果、封面和视频链接。示例内容只用于展示结构，不冒充真实经历。

## 可访问性与性能

- 语义化 section、nav、button 和 heading 层级。
- 图片提供 alt，视频提供 controls、poster 和无障碍文本。
- 支持键盘焦点状态与 `prefers-reduced-motion`。
- 不加载外部框架；字体使用系统回退并控制资源体积。

## GitHub Pages 发布

README 提供创建仓库、推送代码、在 Settings → Pages 中选择 `main` 分支根目录的步骤，并说明发布后的 URL 格式。所有链接使用相对路径，确保项目仓库和用户主页仓库均可工作。
